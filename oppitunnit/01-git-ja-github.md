## Git

Git on hajautettu versionhallintajärjestelmä, joka tallentaa muutokset paikallisesti tietokoneellesi ja mahdollistaa niiden synkronoinnin etäpalvelimen kanssa. Gitin avulla voit seurata tiedostojen muutoksia, tehdä yhteistyötä muiden kehittäjien kanssa ja hallita projektin eri versioita.

Hajautettu tarkoittaa, että jokaisella kehittäjällä on oma täydellinen kopionsa projektin historiasta paikallisesti tietokoneellaan. Tämä mahdollistaa työskentelyn offline-tilassa ja vähentää riippuvuutta keskitetystä palvelimesta.

Git on pohjimmiltaan komentoriviltä suoritettava sovellus, mutta siihen on saatavilla myös graafisia käyttöliittymiä, jotka helpottavat sen käyttöä erityisesti aloittelijoille. Se on myös integroitu moniin kehitysympäristöihin (IDE), mikä tekee sen käytöstä entistä sujuvampaa. Komentorivipohjainen käyttö vaatii aluksi hieman harjoittelua, mutta tarjoaa suurimman joustavuuden ja tehokkuuden. Ja toisinaan esim. palvelinympäristössä on välttämätöntä käyttää komentoriviä.

## GitHub

GitHub on pilvipalvelu, joka tarjoaa Git-repositorion hostaamisen ja yhteistyöominaisuudet. GitHubin avulla voit jakaa projekteja muiden kanssa, seurata muutoksia, hallita tehtäviä ja hyödyntää erilaisia yhteistyötyökaluja, kuten pull requesteja ja issueja, jotka eivät ole perus Gitin ominaisuuksia.
